# Screenshot-Ordner

Lege hier deine Screenshot-Paare in Unterordnern ab.

## Struktur

```
screenshots/
├── paar_001/
│   ├── reference.png    # Referenzbild (Screenshot A)
│   └── comparison.png   # Vergleichsbild (Screenshot B)
├── paar_002/
│   ├── reference.png
│   └── comparison.png
└── ...
```

## Namenskonvention

Die Standardnamen sind `reference` und `comparison`, aber du kannst in der App andere Patterns konfigurieren, z.B.:

- `_a` / `_b`
- `before` / `after`
- `original` / `test`

## Unterstützte Formate

- PNG (.png)
- JPEG (.jpg, .jpeg)
- WebP (.webp)
- GIF (.gif)
